## 第三步：开启实时推送通知（强烈推荐）

登录后，在 Dashboard 顶部找到 **「🔔 开启推送」** 按钮。

### 安卓用户（最简单）

1. 用 **Chrome**（或三星浏览器、Edge 等）打开网站并登录
2. 点顶部「🔔 开启推送」
3. 浏览器弹出权限提示 → 选「**允许**」
4. ✅ 完成，以后有新帖直接弹系统通知

无需安装 App，无需保存到桌面，在普通浏览器标签页里就能用。

> ⚠️ **不支持在微信里直接打开**。请长按链接 → 选「用浏览器打开」，或复制链接到 Chrome。

### iPhone 用户（需要多一步）

苹果限制较多，需要先把网站保存到主屏幕：

1. 用 **Safari** 打开网站并登录
2. 点底部 **分享按钮**（方块加箭头图标）
3. 选「**添加到主屏幕**」→ 右上角点「添加」
4. 从主屏幕图标重新打开网站
5. 点「🔔 开启推送」→ 允许

> ⚠️ iPhone 上只有 Safari 支持，Chrome / 微信打开均不支持推送。

之后有新帖时，即使屏幕锁定，也会弹出通知。

## 常见问题

**Q：收不到推送怎么办？**  
A：确认已点「🔔 开启推送」且显示绿色「推送已开」。安卓请用系统浏览器；iPhone 请从主屏幕图标打开网站。

**Q：WxPusher UID 怎么找？**  
A：打开 WxPusher → 右下角「我」→ 点头像，UID 显示在用户名下方。

**Q：登录页面发不出验证码？**  
A：确认你的 UID 已被管理员授权，且 WxPusher 里已关注 Serenity 主题。

**Q：忘记账号密码？**  
A：联系管理员 **微信 PM112629** 重置。

**Q：Dashboard 打开是空白的？**  
A：清除浏览器缓存后重试，或换 Chrome / Safari 浏览器。
